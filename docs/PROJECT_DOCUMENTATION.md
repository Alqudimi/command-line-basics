# Project documentation

## Overview

command-line-basics is a bilingual learning resource covering command-line fundamentals across generic shell usage, Linux, and PowerShell. It includes Markdown lessons, an HTML index, and page-specific material.

## Content structure

Use `CMD.md`, `Linux.md`, and `PowerShell.md` as the primary topic guides. The `pages/` directory contains the web presentation of the material, while `index.html` provides the entry point.

## Contribution guidance

Keep commands tested on the stated platform, explain expected output and permissions, mark destructive operations clearly, and provide equivalent commands when behavior differs between shells.
